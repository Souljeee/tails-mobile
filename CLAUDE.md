# CLAUDE.md

Инструкции для Claude и Claude Code при работе с этим репозиторием.

## Обязательные документы

Перед анализом задачи, изменением файлов или запуском команд полностью прочитай и соблюдай:

1. [AGENTS.md](AGENTS.md) — обязательные правила репозитория, ограничения и проверки.
2. [Руководство по агентской разработке](docs/agent-development-guide.md) — подробные соглашения по
   архитектуре, BLoC, навигации, UI kit, тестированию и рабочему процессу.

Правила из этих документов являются частью этого файла и имеют такую же обязательную силу.
Если инструкции противоречат друг другу, используй следующий приоритет:

1. Явные требования текущей задачи пользователя.
2. Ближайший к изменяемому файлу вложенный `CLAUDE.md` или `AGENTS.md`.
3. Корневой `AGENTS.md`.
4. `docs/agent-development-guide.md`.
5. Этот файл.

## Краткие ограничения

- Продолжай существующую feature-first архитектуру и используй `Bloc` для бизнес-состояния.
- Для экранов используй типизированный `go_router`.
- Строй интерфейс на компонентах и токенах из `lib/src/core/ui_kit`.
- Выноси UI-секции в отдельные виджеты, а не в `_build*` методы, возвращающие `Widget`.
- Не редактируй generated-файлы вручную.
- Не изменяй несвязанный код и не перезаписывай пользовательские изменения.
- Перед завершением отформатируй затронутый код, запусти релевантные анализ и тесты, затем проверь
  итоговый diff.

Не копируй сюда подробные правила из связанных документов. При изменении подходов обновляй
`AGENTS.md` или руководство, сохраняя этот файл компактной точкой входа.
